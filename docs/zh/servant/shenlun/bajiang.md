# 申论写作八讲

+ 区分轻重缓急，体现条理清晰：从最紧要、最关键的事情说起，把相关的、该做的事情逐项说清楚、说全面
+ 明确措施目的，体现合理可行

## 申论学习的四项基本训练
### 删减练习
删减对象：一句话里的背景、细节、程度、也可以是一段话里的主体、过程、效果。
- 背景往往起到铺垫的作用，细节和程度往往是补充信息，都可以删除。
- 主体：当是谁做的不言而喻时，或者前文出现过都可删
- 过程：如果是阶段性的，可删。比如资金是怎么申请的，过程往往不重要，申请到资金才重要
- 效果，如果是理所应当并且比较抽象时，可删。当效果以目标的形式出现时可以保留
- 还可以删除修饰、罗列的内容。
### 替换练习
给定资料提供的信息往往是具体而琐碎的，但答案要求概括并且有字数限制，这就要求用更加凝练的语言，把给定资料想表达的意思表达出来，这就是替换。
