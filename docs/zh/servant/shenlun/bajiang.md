# 申论写作八讲

+ 区分轻重缓急，体现条理清晰：从最紧要、最关键的事情说起，把相关的、该做的事情逐项说清楚、说全面
+ 明确措施目的，体现合理可行

## 申论学习的四项基本训练
### 删减练习
删减对象：一句话里的背景、细节、程度、也可以是一段话里的主体、过程、效果。
- 背景往往起到铺垫的作用，细节和程度往往是补充信息，都可以删除。
- 主体：当是谁做的不言而喻时，或者前文出现过都可删
- 过程：如果是阶段性的，可删。比如资金是怎么申请的，过程往往不重要，申请到资金才重要
- 效果，如果是理所应当并且比较抽象时，可删。当效果以目标的形式出现时可以保留
- 还可以删除修饰、罗列的内容。
### 替换练习
给定资料提供的信息往往是具体而琐碎的，但答案要求概括并且有字数限制，这就要求用更加凝练的语言，把给定资料想表达的意思表达出来，这就是替换。
- 春节、元宵节、端午、中秋、重阳等可以替换为“重要民俗节庆”
- 窨井盖、电表箱、电线杆等可以替换为“市政设施”
- 安全饮水配套工程、电信宽带替换为“基础设施建设”或者“基建”
- 每天早上，摊贩们将小巷堵得严严实实，出行极不方便 -> 影响交通|摊贩占道经营
- 大清早就吵吵闹闹，觉也睡不好 -> 影响居民休息

### 仿写练习
- 高段位选手主要是借鉴他人的风格、思路
- 普通考生应从具体文字的仿写开始，在保留原文的结构的基础上，根据不同的主题填充相应的内容。从简单的仿写一句一段，逐步到仿写一篇文章，当自己“骨骼强壮”之后，就可以挣脱仿写的壳，自由地创作了。

### 改写练习
#### 四变运用法
- 个别到一般
- 单一到多元
- 现象到本质
- 正面到反面

## 归纳概括题的答题策略与巩固练习
### 解题步骤
1. 逐句逐段分析，读懂材料意图
   1. 以一句话为一个要素单元，数一数一个自然段有几句话，理解每句话的意思
   2. 将一个自然段内每句话的意思联系起来，理解整段话的意思
   3. 结合每个自然段的意思，理解整则给定资料的意思
2. 判断要点数量，估算字数分布
   1. 根据材料的行文逻辑，判断答题要点以什么形式分布。是每段一个要点？还是邻段合并为一个要点？还是一段内有多个要点？
   2. 对给定资料中位置相近、内容相似的答题要点暂且归为一类，再统计要点数量。
   3. 根据题目字数要求，给每个答题要点平均分配字数。
3. 材料去辅留主，找出可答原词
   1. 找到给自资料中设计答题要点的部分，识别出关键信息和次关键信息。
4. 需要区分要点，理顺答案逻辑
